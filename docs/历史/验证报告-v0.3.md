## 资源接入与待完成事项

Poly Haven 三组资源使用 CC0，原始文件和校验清单位于 Assets/Source/PolyHaven。道具使用简单盒碰撞、三档 LOD 和单材质槽；贴图运行上限 1024，地面每 3 米重复。仓库加入十二个木箱和六个油桶，保留原中央通道和对称出生区。来源与复现命令见 docs/资源来源.md、docs/免费资源与真实感优化方案.md。

首轮地面材质曾因 ComponentMask 输入连接不正确回退为默认材质。修复连接并重建生成材质后重新烘焙，最终包无该警告，已核对实际截图。早期 Saved/package-windows-v03.log 不作为最终验收依据。

Quantum 免费样例的 FBX 源文件已下载，人物和步枪已导入 Content/ThirdParty/Quantum。人物包含 351 根骨骼、14 个材质槽、一个 LOD；导入日志出现绑定姿势缺失、权重截断和零长度法线警告。1.13 GB PBR 材质包下载未完成，尚需网格修复、UE4 动画适配和移动端骨骼 / 材质预算优化。当前发布包未引用这些测试资源，也未完成写实人物、持枪 IK、射击和换弹动画。

Factory Environment Collection 与 Animation Starter Pack 已领取到 Fab 账号资源库，尚未下载 UE 文件。网页明确要求通过 Epic Games Launcher 或 UE5 插件下载，当前工具无法操作 Launcher。在 Launcher 资源库选择“添加到项目”，指定本工程及 UE4.27，或下载到 UE4.27 临时项目再迁移。Fab 原始文件及本地测试资产被 Git 忽略，不作为独立资源上传公开仓库。
