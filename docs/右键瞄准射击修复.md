# 右键瞄准射击修复（v0.5.6）

## 本地瞄具资源检查

遵照本次要求，仅检查和使用已经下载的资源，没有下载新资源。

- Quantum 原始 FBX 包包含 12 个模型文件，其中武器为 `FBX/SM_Rifle.fbx`。导入内容为现有步枪、枪身和弹匣，未找到独立的红点或全息瞄具。
- Factory Environment Collection 和 Poly Haven 的本地内容为场景模型、贴图和天空资源，未找到可用瞄具。
- Animation Starter Pack 内的 `Ironsights` 文件是机械瞄准动作，不能当作红点 / 全息瞄具模型。

因此本版不新增瞄准镜，右键仍采用现有第三人称肩射瞄准、缩小视野和准星。

## 修复内容

瞄准开火曾复用腰射片段，枪械位置又偏向双肩中心，枪身容易靠近下巴。本版使用已经导入的 `ASP_Fire_Rifle_Ironsights` 播放瞄准射击；腰射继续使用原来的片段。

瞄准持枪改到右肩外侧、略向前和向下，后坐的向后位移从 2 cm 限制到 0.5 cm。抬枪期间立即开火时，武器采用对应的瞄准握枪位置，让动画和枪械姿态在第一发就匹配。

大角度瞄准和近掩体收枪时，支撑手沿枪身后移，防止左臂超过可达范围。换弹仍使用已有动作，在抽取弹匣阶段回到原有近身位置，完成后恢复新的瞄准位置。枪、双手与弹匣继续使用同一帧的最终姿态快照。

## 验证

`TestWeaponPose.ps1` 检查原有站姿 / 蹲姿、掩体与换弹，并新增站姿及蹲姿瞄准连发、上下 30° / 60°、右键与左键同时按下的回归。逐帧检查双手握枪误差和头部避让包络。

头部检查取 `head` 骨骼上方 6 cm 的参考点，对步枪枪托至机匣顶部线段计算距离；15 cm 阈值包含近似头部半径、枪身半宽和间距。这个检查用于检测本次复现的问题，并非人物与武器全部三角形的精确碰撞检测。固定模拟步长用于连续采样，不能据此判断真实帧率。

```powershell
Set-Location D:\TPSDuel
.\tools\TestWeaponPose.ps1
.\tools\TestControls.ps1
.\tools\TestLocomotion.ps1
.\tools\TestNetwork.ps1 -Packaged -Aiming -Facing
.\tools\TestNetwork.ps1 -Packaged -Aiming -Crouched
```
