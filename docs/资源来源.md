# 资源来源

仓库布局、组合武器、Slate 界面和占位枪声音效由本项目制作。参考其他射击游戏的信息布局，没有复制其资产或标识。

人物与基础动画来自本机 UE4.27.2 安装：

`D:/Program Files/Epic Games/UE_4.27/Templates/TemplateResources/Standard/Mannequin/Content`

项目路径：`Content/Mannequin`。包含人物网格、骨架、物理资源、材质、基础待机/跑步/跳跃动画及其动画蓝图。保留原目录以保持资产内部引用有效。

仓库贴图来自：

`D:/Program Files/Epic Games/UE_4.27/Samples/StarterContent/Content/StarterContent/Textures`

只复制 Concrete_Poured、Brick_Clay_Old、Wood_Pine、Metal_Steel 的 D/N 贴图，共八份资源；项目路径为 `Content/StarterContent/Textures`。自建材质由 `tools/InitializeAssets.py` 在 UE 编辑器内生成，已限制贴图最大运行分辨率为 1024。

这些 Epic 随引擎提供的资源用于 UE 游戏开发，仍受相应 Epic 许可约束。本项目没有将它们当作可自由重新授权的独立资源包。
