核查日期：2026-10-05。第一批 CC0 扫描资源已接入仓库；v0.3.1 将已下载的 Quantum 人物和步枪接入角色，并适配 UE4 移动动画。人物仅手臂使用已恢复的原始贴图，其余材质为临时基础材质。完整工厂包仍未下载。手机实测尚未完成。

## 需要补充什么

界面与三维画面分别处理：菜单、比分、血条、准星和触屏按钮可以继续在现有 Slate 界面中优化；真实的人物、枪械和仓库则需要模型、材质、骨架动画及灯光共同配合。

当前项目使用引擎 Mannequin 与基础移动动画，枪械是简化组合模型，仓库建筑和掩体主要由基础几何体构成。下一阶段优先解决人物持枪姿态、枪械外观和场景材质，而不是仅增加模型数量。

## 接入顺序

1. **人物动作与武器**：先以现有 Mannequin 核对动画包，完善持枪移动、瞄准和开火表现；把真实枪械挂到手部插槽，调整左手 IK，让手握住枪。换弹需要相应动作和动画通知，不能仅替换模型。
2. **人物外观**：在单独的资源测试目录导入免费人物样例。确认骨架重定向、蒙皮和移动端材质后替换角色外观，以局部蓝红标识区分队伍。
3. **仓库场景**：先替换地面与墙面材质，再选用工业包中的钢柱、门和仓储道具。保持原 1v1 路线及掩体关系，重新核对角色通行、移动碰撞与射击遮挡。
4. **灯光与画面**：改善明暗层次、粗糙度和接触阴影；静态场景可评估烘焙灯光，控制动态阴影开销。
5. **验证与发布**：检查 Windows 画面和双进程联机，再打包 Android，在实际手机上测帧率、发热、内存和操作可读性。

## UE4.27 与手机的约束

- 优先获取原生支持 UE4 的资源。UE5 的 `.uasset` 不应直接复制进 UE4.27；有 FBX 源文件的模型可尝试重新导入，但材质、骨架和动画仍需适配。
- [UE4.27 官方 FBX 骨骼网格流程](https://dev.epicgames.com/documentation/en-us/unreal-engine/fbx-skeletal-mesh-pipeline?application_version=4.27)使用 FBX 2018，导出版本不同可能产生兼容问题。
- 初始贴图以 1024 为主，确有需要的角色和近景使用 2048；建立 LOD，减少材质槽和透明材质，装饰细节使用简单碰撞或不设碰撞。具体预算由手机实测决定。
- 当前只有手机系统相关版本字符串，不能据此判断 GPU、可用内存或稳定帧率，因此不保证大型资源包原样导入后的手机性能。

第一批建议范围：一个可用人物、一把步枪、一套持枪动作、少量工业组件和一组地面材质。完成接入后再决定是否扩充道具与视觉特效。

## 复现与资源保存

```powershell
Set-Location D:\TPSDuel
.\tools\FetchFreeAssets.ps1
.\tools\Build.ps1 -Action Bootstrap
```

下载脚本通过 Poly Haven 官方 API 获取文件，核对官方 MD5，并记录本地 SHA-256。原始文件和清单位于 `Assets/Source/PolyHaven`；导入报告位于 `Saved/FreeAssetsImport.json`。

Fab 源文件放在 `Assets/Source/Fab/Quantum`，导入位于 `Content/ThirdParty/Quantum`。两者已加入 `.gitignore`，不把受许可约束的独立资源提交到公开仓库。取得自己的资源后，可使用下列命令重新导入网格：

```powershell
& 'D:\Program Files\Epic Games\UE_4.27\Engine\Binaries\Win64\UE4Editor-Cmd.exe' 'D:\TPSDuel\TPSDuel.uproject' '-ExecutePythonScript=D:\TPSDuel\tools\ImportQuantumAssets.py' -unattended -nosplash -NullRHI
```

`Saved/QuantumImport.json` 的 `state=staged` 只记录原始 FBX 导入，不表示后续适配完成。继续执行 `tools/Build.ps1 -Action Bootstrap`，会在存在恢复贴图清单时运行 `PrepareQuantumAssets.py`；检查 `Saved/QuantumPreparation.json` 的 `state=prepared`、动画路径、LOD 和临时材质列表。编辑器模块需要先编译；材质、动画与实际画面仍须结合构建和截图验证。

首次导入未保存关联骨架的问题已修复：导入脚本现在同时保存关联资产目录，并在已存在网格缺少骨架时重新导入。重定向资产保存在 `Content/ThirdParty/Quantum/Animations`，原 Mannequin 动画保持原样，便于重新适配。
