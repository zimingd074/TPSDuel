# 资源来源

仓库布局、组合武器、Slate 界面和占位枪声音效由本项目制作。参考其他射击游戏的信息布局，没有复制其资产或标识。

人物与基础动画来自本机 UE4.27.2 安装：

`D:/Program Files/Epic Games/UE_4.27/Templates/TemplateResources/Standard/Mannequin/Content`

项目路径：`Content/Mannequin`。包含人物网格、骨架、物理资源、材质、基础待机/跑步/跳跃动画及其动画蓝图。保留原目录以保持资产内部引用有效。

仓库贴图来自：

`D:/Program Files/Epic Games/UE_4.27/Samples/StarterContent/Content/StarterContent/Textures`

只复制 Concrete_Poured、Brick_Clay_Old、Wood_Pine、Metal_Steel 的 D/N 贴图，共八份资源；项目路径为 `Content/StarterContent/Textures`。自建材质由 `tools/InitializeAssets.py` 在 UE 编辑器内生成，已限制贴图最大运行分辨率为 1024。

这些 Epic 随引擎提供的资源用于 UE 游戏开发，仍受相应 Epic 许可约束。本项目没有将它们当作可自由重新授权的独立资源包。

## Fab 资源测试目录

[Quantum Modular Character Free Sample](https://www.fab.com/listings/8e200050-3158-4762-b297-f785b5b1533d) 的完整 FBX 已下载并导入 `Content/ThirdParty/Quantum`。v0.3.1 的角色引用其人物和步枪模型，以及复制重定向的 UE4 移动动画。采用 [Fab Standard License](https://www.fab.com/eula)，不可作为独立资源包公开分发；Fab 原始文件和导入资源已被 Git 忽略。

1.13 GB PBR 包仍是中断下载文件。通过 `tools/RecoverQuantumTextures.py` 只恢复三张已完整下载并通过 ZIP CRC / 长度校验的手臂贴图，未使用截断文件。其余材质使用项目生成的临时颜色 / 粗糙度 / 金属度参数，不能视为原作者完整材质。清单在 `Assets/Source/Fab/Quantum/RecoveredTextures.json`，运行贴图上限 1024。

`tools/PrepareQuantumAssets.py` 配置材质、生成三档 LOD，并调用 `Source/TPSDuelEditor` 的编辑器资源工具重定向原 Mannequin 移动动画。初始持枪姿态写入复制片段，原始动画未被改写。

[Factory Environment Collection](https://www.fab.com/listings/2ee66462-8c2b-4303-892c-83f7fc0d9b3e) 与 [Animation Starter Pack](https://www.fab.com/listings/98ff449d-79db-4f54-9303-75486c4fb9d9) 已领取，仍待 Launcher 下载。动画包页面额外注明 UE-Only Content。接入前记录实际下载版本并核对许可，勿将完整包上传公开仓库。
