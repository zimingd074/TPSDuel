# TPSDuel v0.5.1 移动与射击优化验证报告

首次构建与测试日期：2026-10-06；交付与恢复复验日期：2026-10-07。UE4.27.2，工程 D:\TPSDuel。改动与设计见 [移动与射击优化](移动与射击优化.md)。上一版资源升级报告保存在 [v0.5.0 历史报告](历史/验证报告-v0.5.0.md)。

## 实现结果

- 移动时采用低位持枪，完整持枪姿态枪口俯角约 32°、横向约 40°。瞄准、射击、换弹恢复对应姿态；枪、手和弹匣仍用同帧 IK 目标。
- 非瞄准移动统一为 375 cm/s，取消侧移、倒退及斜向的额外降速；瞄准为 120 cm/s。组合输入由 CharacterMovement 归一化。
- 前后左右步态加入左右脚同步标记，8 段循环各 4 个标记；Jog 播放速率 1.389，Walk 为 1.250。方向按最短角度平滑过渡，斜向 IK 补偿水平步幅，保留原脚步节奏和高度。
- 连发间隔 0.075 秒，设定射速 800 发/分钟。服务器和客户端反馈保留下一发目标时间，避免帧量化累积降速；发生长卡顿时不集中补发。重新按下扳机仍按上次真实射击时刻检查冷却。
