## 修复与实际限制

为仓库加入法线纹理、粗糙度、金属度、屋顶开口、日光和环境光。开启 Mobile HDR，限制所选场景贴图最大运行分辨率为 1024；首次新平台烘焙会编译着色器。人物采用 UE 自带训练用人形模型及移动动画，武器为简化零件，没有完成专业服装、持枪 IK、射击或换弹动画。

独立包人物最初回退为灰色默认材质，最终通过给 M_Paint 启用 used_with_skeletal_mesh 并重新烘焙修复。构建脚本在进程内设置 Git core.quotepath=false，绕过 UE4.27 Git 工作集解析中文文件名的异常；没有修改引擎或全局 Git 设置。

APK 使用同一 Android Debug 开发签名，包名 com.tpsduel.prototype，StoreVersion=2，VersionDisplayName=0.2.0。当前没有自动更新功能，更新采用完整 APK 覆盖安装；后续发行递增 StoreVersion，并保持原签名。正式发布需另行规划发布密钥和商店适配。

原生工具链仍为 NDK r21e / API 30 / arm64，尚未进行 16 KB 页适配。用户给出的 6.12.58-Android16-6 不能替代型号、完整系统 API、ABI 与页大小检测。手机安装启动、PC 与手机同局、多人触控、发热及帧率仍待实测。
