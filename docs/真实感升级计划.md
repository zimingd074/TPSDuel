## 资源管理

- 已授权领取本次免费资源及接受相关 Fab 协议；只下载免费范围，遇到收费资源不购买。
- Poly Haven / ambientCG 为 CC0；Fab 免费不等于 CC0，保留许可记录，不将受限制的原始或派生独立资产上传公开 Git。
- UE5 `.uasset` 不直接复制到 UE4.27；选择 4.27 包或 FBX / 通用贴图重新导入。
- 源文件保存到 `Assets/Source`，UE 资源按来源保存到 `Content`，导入和验证报告保存到 `Saved`。工具、计划、来源记录和验证截图保存到 Git。
- 场景贴图优先 1K，必要的人物近景使用 2K；模型使用 LOD、简单碰撞、尽量少的材质槽。大型展示地图不整体搬入。

1. 先保留 v0.4.2 包作为回退与覆盖安装基线；升级后的版本号、APK versionCode 均递增。

3. 查看实际游戏截图，检查人物材质、光照、设施、地面细节和动作。截图必须来自实际构建。
4. 打包 Windows / Android，运行视口输入、动作和双客户端联机测试。
5. 校验 APK 包名、签名、版本递增和内置游戏数据。手机未连接时明确记录未实测。
