# v0.2 界面与工业仓库

参考竞技射击游戏的信息层次和可读性，采用本项目原创的深色、砂金、蓝红配色与布局。没有使用 CS、和平精英的商标、界面截图或游戏资源。

## 界面

- 主菜单显示仓库背景、创建房间和 IP 加入入口、版本号及连接状态。
- 顶部集中显示蓝红双方比分、三次击杀目标、开局倒计时及结果；结算后双方点击 PLAY AGAIN。
- 左下显示生命值、血条和重生保护；右下显示 AR-01 自动武器与弹匣数量。换弹时显示 RELOADING。
- 准星用四条线绘制，移动时扩散、瞄准时收紧，命中时出现短暂砂金色反馈。
- 手机左侧浮动圆形摇杆、右侧拖动视角；FIRE、AIM、RELOAD、JUMP 保留独立多点触控。按钮放在弹药面板上方，避免遮挡状态。
- 界面以 1280×720 作为逻辑尺寸，按屏幕等比缩放，保持按钮和文字比例。超宽屏会留出两侧空白，3D 场景仍占满画面。

当前界面使用英文以适配 UE 自带字体。中文本地化需要加入合适的可分发字体及字形打包配置。

## 场地

DEPOT 07 是 36×24 米的对称仓库。两侧出生点、中央高低掩体与原测试场对应，新增蓝红钢制集装箱、木制货箱、卷帘门、砖墙、钢柱、顶梁和地面交通线。装饰细节没有额外碰撞；主体掩体和建筑阻挡移动与射击。

混凝土、砖、木、钢材包含底色和法线贴图；贴图运行分辨率上限为 1024。天空和屋顶开口提供环境光与日光，采用一盏可移动方向光和两级阴影，不添加大批动态点光源。开启 Mobile HDR、关闭自动曝光、泛光和运动模糊。手机帧率仍需真实设备测量。

使用引擎安装目录中的 Starter Content 纹理及 Standard Mannequin 人物、骨架和基础移动动画。相关资源随本 UE 工程使用，来源及路径见 `docs/资源来源.md`。人物仍是训练用人形模型，武器由简化零件构成；没有完成专业人物服装、持枪 IK、射击和换弹动画。

## 验收

先检查 Windows 主菜单、游戏 HUD 和模拟手机横屏布局的实际截图，再运行双进程联机回归验证射击、重生和比分。Android 打包成功后，还要在手机验证覆盖安装、正常启动、多指操作、画面亮度、发热和帧率。
