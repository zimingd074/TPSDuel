# 移动朝向优化（v0.5.5）

按镜头的水平前向解释移动输入。普通移动时人物平滑转向移动方向；倒退时回到镜头前向，沿反方向退步。镜头仍由鼠标或手机右侧触屏控制，人物转向不会带动镜头旋转。

| 输入 | 人物朝向（相对镜头前向） | 移动动作 |
| --- | --- | --- |
| W | 0° | 向前跑 |
| W + A | 左前 45° | 转向后向前跑 |
| W + D | 右前 45° | 转向后向前跑 |
| A / D | 左 / 右 90° | 转向后向前跑 |
| S | 0° | 面向镜头前向倒退 |
| S + A / S + D | 0° | 使用原有后斜方向持枪动画 |
| 无移动输入 | 回到镜头前向 | 停步 |
| 瞄准或按住开火 | 面向准星 | 保留对应方向的持枪移动动画 |

转身速度为每秒 540°；瞄准或首次开火立即对齐准星，避免转身过程中枪口仍指向移动方向。松开瞄准或开火后恢复移动转向。手机左侧摇杆使用相同规则。

本版继续使用现有 Animation Starter Pack 持枪移动、射击和换弹动作，以及蹲姿 IK 与近掩体收枪处理。移动速度保持普通 375、瞄准 120、静步 150、下蹲 120、下蹲加静步 80 cm/s；斜向输入沿用 CharacterMovement 的归一化，避免额外加速。

## 代码与联机

`UDuelCharacterMovement::ComputeOrientToMovementRotation` 区分前向、侧向与后向输入；普通旋转走 UE 原有 `PhysicsRotation`。瞄准 / 射击朝向模式通过自定义 SavedMove 的 `FLAG_Custom_1` 传给服务端，并参与预测回放与移动合并判定。静步继续使用 `FLAG_Custom_0`。远端玩家沿用原生角色移动复制与平滑。

## 验证方式

```powershell
Set-Location D:\TPSDuel
.\tools\Build.ps1 -Action Tests
.\tools\Build.ps1 -Action PackageWindows
.\tools\TestControls.ps1
.\tools\TestLocomotion.ps1
.\tools\TestWeaponPose.ps1
.\tools\TestNetwork.ps1 -Packaged -Facing
```

输入回归覆盖 W+A、W+D、斜跑瞄准 / 射击、松开射击、从斜跑切换 S，以及蹲下静步斜行。动作回归采集八方向、跳跃和持枪姿态；联机专项检查双方看到的斜向身体转向、倒退回正，并完成换弹、伤害、重生与 3 杀胜负。最终结果与安装包见 [验证报告](验证报告.md)。
