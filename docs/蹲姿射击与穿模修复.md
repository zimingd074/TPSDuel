# 蹲姿射击与枪械穿模修复 v0.5.4

本轮处理蹲下射击时手肘抬得过高，以及枪械在瞄准角度变化和贴近掩体时穿模的问题。Ctrl 下蹲、Shift 静步和原有移动速度保留。

## 修改

- 手肘 IK 引导点改为相对各自肩部向外、向下，不再使用固定的站姿高度。枪、双手与弹匣继续使用同一帧的姿态快照。
- 持枪位置跟随动画实际肩部的三维位移，适应下蹲、胸部前倾和射击动作；替换只跟随骨盆高度的计算。
- 瞄准与后坐力绕枪托接触点旋转，减少枪托在抬头、低头时插进胸部或头部。大角度瞄准时把枪移到身体外侧，支撑手在前护木上略向后调整。
- 对未收枪状态的枪托到枪口做半径 6 cm 的球形碰撞扫描；碰到掩体时立即把枪侧收，离开后平滑恢复，双手随枪一起调整。
- 保留服务器原有枪口阻挡检测。贴墙开火仍消耗弹药，射线被掩体挡住；收枪是视觉姿态调整，不改变伤害权限。

## 验证方法

```powershell
Set-Location D:\TPSDuel
.\tools\TestWeaponPose.ps1
.\tools\TestControls.ps1
.\tools\TestLocomotion.ps1
.\tools\TestNetwork.ps1 -Packaged
.\tools\TestNetwork.ps1 -Packaged -Crouched
```

新增姿态回归实际连续开火，检查站姿与蹲姿腰射、瞄准射击的手肘和右手高度，以及双手握枪误差；覆盖上下 60° 瞄准、蹲姿换弹、靠墙收枪和移除墙体后的恢复。测试墙位于人物前方 65 cm，厚度 8 cm，并验证收枪后枪口留在墙体近侧、服务器射击命中测试墙。

最终构建、截图与真机验收状态见 [验证报告](验证报告.md)。碰撞与 IK 测试覆盖指定姿态和障碍；复杂掩体边角、所有瞄准角度与动画过渡仍需实际游玩检查。
