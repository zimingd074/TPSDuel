# v0.5.1 移动与射击优化

## 问题与实现

- 走动、跑步使用低位持枪：枪口斜向下约 32°，横向约 40°；瞄准、开火及换弹平滑恢复各自姿态。双手与枪继续使用同帧 IK 目标。
- 移除侧移约 200 cm/s、倒退 220 cm/s 及斜向速度衰减。非瞄准的八个移动方向均为 375 cm/s；瞄准仍为 120 cm/s。沿用 CharacterMovement 对组合输入的归一化，W+A / W+D 不会叠加加速。
- 方向变化按最短角度平滑过渡，前后左右步态加入左右脚同步标记；斜向移动补偿混合后变短的水平步幅，保持原脚步节奏和高度；根据原始步幅校正播放速率。Jog 使用原 BS_Jog 的 270 cm/s 基线适配 375 cm/s，Walk 使用约 150 cm/s 基线适配混合空间中间档 187.5 cm/s。
- 连发间隔由 0.1 秒改为 0.075 秒，设定射速由 600 发/分钟提高到 800 发/分钟。服务器保留下一发的目标时间，调度单次定时器；帧间隔造成的迟发不会累积成长期降速。长时间卡顿后恢复正常间隔，避免集中补发。重新按下扳机仍按上次真实射击时间检查冷却，防止快速点按绕过限制。客户端预测反馈采用相同间隔，快速点击仍受冷却限制。

## 验收

- 自动化：检查低位枪口朝向与 0.075 秒冷却边界。
- 动作采样：22 帧，包含前后左右、四个斜向方向、跳跃、瞄准、开火及换弹。检查实测速度、混合方向、低位持枪及握枪误差；人工查看真实运行截图。
- 连发：持续按住鼠标，在固定 30 Hz 和变化模拟步长下分别测量一秒射击数，检查丢发和冷却绕过。测试模拟步长不影响正常游戏时钟。
- 回归：鼠标捕获、松开、菜单、换弹、倒计时和双进程联机。
- 发布：Windows / Android v0.5.1，versionCode 9。与 v0.5.0 对比包名、签名和版本号。手机未连接时保留真机待验收结论。

Windows 与 Android 构建、规则自动化、22 帧动作采样、两种步长下的连发和双进程联机均已通过；2026-10-07 完成交付记录，详见 [v0.5.1 验证报告](历史/验证报告-v0.5.1.md)。Android 16 真机验收待手机连接后进行。
