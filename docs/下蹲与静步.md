# 下蹲与静步 v0.5.3

按住 Ctrl 下蹲，松开后站起；左右 Ctrl 都支持。按住 Shift 静步，松开恢复正常移动；左右 Shift 都支持。两者可以同时按住。手机使用右侧新增的 CROUCH 和 WALK 按钮，同样按住生效、松开恢复。

| 状态 | 地面移动速度 |
| --- | --- |
| 普通移动 | 375 cm/s |
| Shift 静步 | 150 cm/s |
| Ctrl 下蹲移动 | 120 cm/s |
| Ctrl + Shift | 80 cm/s |

瞄准仍限制为 120 cm/s，因此瞄准时按 Shift 不会加速；蹲姿静步瞄准保持 80 cm/s。当前游戏尚未播放脚步声音，静步功能控制移动速度，没有新增声音传播或敌方听觉系统。

## 动作与操作

- 站姿保留 v0.5.1 的持枪方向移动、低位持枪、射击与换弹。蹲姿使用已有 Animation Starter Pack 的持枪蹲姿待机及前后左右移动，双手和枪械继续使用现有 IK。
- 站立与下蹲姿态以 0.15 秒混合，镜头高度随下蹲调整。服务器射击视点和枪口高度同步采用蹲姿高度。
- 下蹲胶囊半高为 58 cm，站立为 88 cm。头顶有低矮障碍时，松开 Ctrl 会等待空间允许站起，不会直接穿过障碍。
- 菜单、离开和战斗状态清理会释放下蹲与静步输入，避免返回游戏后保持按键状态；遇到低矮障碍时仍遵守站起碰撞检查。
- 下蹲状态采用 UE CharacterMovement 原生预测与复制。静步意图写入 SavedMove 的压缩标志，与移动指令一起传到服务器；服务器复制静步状态供其他玩家和 HUD 使用。

## 使用新版

Windows 启动 `Builds/Windows/WindowsNoEditor/TPSDuel.exe`。Android 使用 `Builds/Android/Android_ETC2/TPSDuel-arm64.apk`，版本为 0.5.3 / versionCode 11。PC 和手机使用配套构建。

构建和回归结果见 [验证报告](验证报告.md)。手机触屏与 Android 16 真机验收以报告中的实际状态为准。
