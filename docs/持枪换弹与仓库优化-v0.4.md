# v0.4 持枪、换弹与仓库优化

## 实际改动

- 双臂 Two Bone IK 与枪身使用同一帧的目标变换；右手握持扳机区域，左手支撑护木，手指沿关节自身弯曲。
- 瞄准时平滑抬枪；开火加入短促视觉后坐，弹道视觉起点跟随实际枪口。服务器伤害和遮挡判定仍采用原规则。
- 2 秒换弹采用分段程序动画：左手从护木移至弹匣，抽出弹匣、移至腰侧、取新弹匣并插入，最后回到扶枪姿势。原步枪不被覆盖，生成 SM_RifleBody / SM_RifleMagazine 派生网格。
- 服务器复制换弹状态和开始时间，远端使用服务器时间计算进度；弹药只在服务器计时完成后补满。死亡 / 结束取消动作。
- 导入 CC0 工厂墙面、窗框、门、路障、工业推车和沙色灰泥材质。墙体具备实体碰撞，模块保持原贴图，修正原 FBX 的布局偏移。新增镜像台阶与平台，保留中央对战通道。
- 原蓝红集装箱改为低饱和工业配色；队伍标识仍在角色补丁与出生线。

## 从源码准备资源

```powershell
Set-Location D:\TPSDuel
.\tools\FetchWarehouseAssets.ps1
.\tools\Build.ps1 -Action Bootstrap
.\tools\Build.ps1 -Action PackageWindows
.\tools\Build.ps1 -Action PackageAndroid
```

Quantum 人物的 Fab 源文件和派生资源仅保留本机，需要先按资源来源文档取得原模型；CC0 仓库资源可由下载工具独立获取。InitializeAssets 已接入仓库导入与战斗姿势工具。动画图节点定义模块使用 UncookedOnly，实际动画计算在运行时 TPSDuel 模块，独立包不包含编辑器代码。

## 运行

电脑使用 Builds/Windows/WindowsNoEditor/TPSDuel.exe。手机覆盖安装 Builds/Android/Android_ETC2/TPSDuel-arm64.apk。电脑选择创建房间，手机与电脑连接同一 Wi-Fi，在游戏中输入电脑局域网 IP。

版本为 0.4.0，Android versionCode=5。旧包保存在 Builds/Releases/0.3.1/Android，包名与签名不变，更新无需先卸载。

## 质量边界

这是一轮可玩原型改进，尚未达到 CS 的专业动画和完整材质品质。换弹不是动作捕捉，弹匣为原网格区域分离；没有精细拉栓、弹匣丢弃物理、手工调整每个接触点或完整武器蒙太奇。衣服和头部仍缺原作者完整 PBR 贴图。真实手机安装、触控、帧率和极端视角穿模需要人工验收。

Epic Factory Environment Collection / Animation Starter Pack 仍未下载，新增仓库模块来自 Poly Haven，不能混淆这两项进度。资源来源、许可和验证证据见资源来源.md、验证报告.md。

基础移动片段仍未补齐独立的持枪侧移、后退和精细跳跃动画；这部分与极端俯仰时的穿模需继续打磨。
