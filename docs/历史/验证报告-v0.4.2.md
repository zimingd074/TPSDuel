# TPSDuel v0.4.2 构建与验证报告

日期：2026-10-05。UE4.27.2，工程 D:\TPSDuel。

本轮完成跑步时胸前斜持枪、鼠标左键修复和动作衔接调整。Windows、Android 均已生成 v0.4.2；手机没有连接，尚未做设备安装和操作验收。此前 v0.4.1 报告已归档到 docs/历史/验证报告-v0.4.1.md。

## 修改与原因

1. 原 CanCombat 只允许 Playing，单人场地停在 Waiting，因此左键即使成功传入也不会开枪。新增 CanUseWeapon，等待阶段允许试射和换弹；伤害仍使用 CanCombat，倒计时 / 死亡 / 结束不允许开枪。正式开局原有 TryStart 会停止练枪并重新生成满状态人物。
2. PC 的 FInputModeGameOnly 原先默认消耗用于捕获鼠标的按下事件。现使用 SetConsumeCaptureMouseDown(false)，并配置 CapturePermanently_IncludingInitialMouseDown，让首次点击及关闭菜单后的第一下点击进入射击绑定。
3. 跑步时用同一枪变换计算两手目标，斜收于胸前；瞄准、射击、换弹时退出收枪姿势。适当修正上身前倾，瞄准移动速度为 120 cm/s，侧移 200，倒退 220，普通前进 375。
4. 新增 UDuelAnimInstance，反向播放倒退时的脚步循环；在持枪控制节点中通过腿部 IK 重定向侧移的脚部轨迹，限制双脚跨到身体另一侧。跳跃保持独立动画序列，不随倒退速率反播。
5. 动态检查发现仅共用输入数据仍会有错帧。现将动画节点实际使用的快照保存在原生动画实例中，在骨骼变换完成回调中应用到枪和弹匣；移动、瞄准和换弹期间保持同帧一致。
6. 开火状态由服务器复制，远端角色也能退出收枪姿势。HUD 补充左键提示、等待区练枪说明，修正 RELOADING 标签溢出。

## 实际限制

本轮侧步、倒退与收枪是现有模板动画的程序适配，不是新的专用动作捕捉动画。足底贴地、急转身和专业换弹动作仍可进一步优化。人物完整原始贴图、资源许可和仓库导入范围沿用此前报告，本次未获取新的资源包。

ADB 未发现连接的设备。Android 16 手机上的覆盖安装、启动、触屏控制、动作效果、两设备联机和性能尚未实测；打包与签名校验不能替代手机验收。更新时 PC 和手机都使用本次版本，并结束旧对局后重新建房。
