# TPSDuel v0.5.6 右键瞄准射击修复验证报告

日期：2026-10-07。UE4.27.2，工程 `D:\TPSDuel`。说明见 [右键瞄准射击修复](右键瞄准射击修复.md)，上一版见 [v0.5.5 历史报告](历史/验证报告-v0.5.5.md)。

## 修改与资源检查

仅使用本地已有资源，没有下载新资源。Quantum 原始 FBX 包含 12 个模型文件，武器为 SM_Rifle；当前导入内容和场景资源中未找到可用的红点 / 全息瞄具，因此没有新增瞄准镜。右键保留第三人称肩射瞄准和原有视野缩放。

本轮切换到已经导入的 ASP_Fire_Rifle_Ironsights 瞄准射击片段，腰射保持原片段。枪械改为右肩外侧持握，瞄准后坐向后位移限制为 0.5 cm；即时右键加左键射击在第一发采用瞄准握枪位置。大角度瞄准和贴墙收枪时支撑手回收，换弹继续采用原有近身弹匣动作。射速、伤害和移动规则保持。
