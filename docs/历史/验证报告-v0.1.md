## 手机兼容性及剩余验收

ADB 当前没有检测到手机。用户提供的 `6.12.58-Android16-6` 保留为原始版本字符串，实际型号、系统 API、CPU ABI 和系统页大小仍待读取。

对 APK 内全部 arm64 动态库的 ELF LOAD 段检查显示 4096 字节对齐。这不是已完成的 16 KB 适配。如果手机 `getconf PAGE_SIZE` 返回 16384，需要实机验证系统兼容模式；兼容模式也不能保证所有应用正常运行。参考 [Android 官方页面大小兼容文档](https://developer.android.com/guide/practices/page-sizes?hl=zh-CN)。

手机连接并授权 USB 调试后，先运行 InspectAndroid.ps1，再运行 InstallAndroid.ps1 -Launch。电脑创建房间，手机连接同一路由器并输入电脑的局域网 IPv4:7777。仍需在实机上检查安装启动、多指触控、双方移动和伤害、重生、比分、重赛、退出重连以及实际帧率；不能把 PC 自动测试通过写成 PC + 手机验收通过。

首版为本地开发测试包，使用开发签名和 API 30 配置，未完成商店发布适配。
