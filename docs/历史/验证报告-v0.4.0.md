## 实现与修复

1. 自建 FAnimNode_DuelWeaponPose 在运行时 TPSDuel 模块计算双臂 IK，游戏线程预先读取瞄准 / 换弹 / 后坐数据，动画求值线程不访问游戏 Actor。动画图节点定义放在 UncookedOnly 模块，避免独立运行时无法载入纯 Editor 模块。
2. 枪身和双手使用同一变换计算目标；右手握持扳机区域，左手支撑护木。手指绕关节自身轴弯曲，保留移动动画的腿部动作。
3. 从 Quantum 原步枪保留每个三角形、UV 和切线，派生独立枪身与弹匣；原 SM_Rifle 不被覆盖。换弹为 2 秒程序动画，分段执行抽出、移向腰部、插回与复位。状态和开始时间由服务器复制，弹药只在服务器完成计时后补满，死亡 / 对局结束会取消换弹。
4. 模块化工厂 FBX 原点保留了作者集合布局，通过边界中心纠正放置偏移。围墙提供碰撞，墙面和窗框为装饰模块；门窗材质、三档 LOD、1024 贴图上限均已保存。
5. 中场使用扫描路障，新增对称台阶与装卸平台；沿用扫描地面、油桶和木箱，降低集装箱颜色饱和度。主体仍包含自建钢梁、集装箱与部分基础掩体，并不是所有几何都已替换。
6. 弹道视觉起点移至实际枪口，服务器仍使用原先的遮挡和伤害规则。

早期黑色 / 未完成着色器截图、纯 Editor 模块载入警告、初次动画图输出 pin 名称错误，以及同时启动两次 UAT 导致的实例冲突，都不作为交付证据。最终证据使用上表的 delivery 日志、图片和文件校验。

## 尚未验收 / 完成

- 衣服、头部、帽子仍使用临时基础材质；原作者完整人物 PBR 包尚未取得。
- 换弹为程序动画，尚无精细拉栓、旧弹匣丢弃物理、专业动作捕捉 / 手工枪械蒙太奇。静态接触点通过不代表所有动作没有穿模。
- 侧移 / 后退腿部仍使用基础移动片段；极端俯仰、跑跳时的接触和穿模需要人工检查。
- Epic Factory Environment Collection 与 Animation Starter Pack 仍未下载；本轮仓库使用 Poly Haven 的 CC0 模块，不能将两者混为同一个资源包。
- 本轮没有真实 Android 手机安装、PC + 手机联机、多指触控或帧率验收。Android 16 / 16 KB 页兼容性、内存、发热与性能仍待实机验证。

Fab 原始文件与 Quantum 派生资源保留本地，Git 忽略规则继续生效。CC0 仓库资源、导入工具及来源记录可纳入版本控制。上版报告与 APK 保留，见 docs/历史/验证报告-v0.3.1.md、Builds/Releases/0.3.1/Android。
