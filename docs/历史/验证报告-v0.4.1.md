# TPSDuel v0.4.1 构建与验证报告

日期：2026-10-05。引擎：UE4.27.2。项目：D:\TPSDuel。

本轮修复角色移动时保持固定姿势的问题，并校准跑步速度、起步和刹停。Windows 与 Android 均已生成 v0.4.1，手机实机安装和操作仍待验收。v0.4.0 报告保存在 `docs/历史/验证报告-v0.4.0.md`。

## 根因与修复

原 Q_ThirdPerson_AnimBP 的跑步状态机和腿部动画数据存在，但持枪节点之前残留了一个没有输入的 ComponentToLocalSpace 节点。最终输出读取了它产生的参考姿势，跑步和跳跃没有进入人物渲染。上轮静态持枪截图只验证了手部目标，未发现运动姿势被截断；本轮增加实际输入驱动的连续动作检查。

`InstallQuantumWeaponPose` 现在清理旧转换节点，重新连接完整主动画链：移动 / 跳跃状态机 → LocalToComponentSpace → DuelWeaponPose 双手持枪 IK → ComponentToLocalSpace → 最终输出。

模板跑步样本的速度为 375 cm/s，之前角色最大速度为 500 cm/s。现在最大速度改为 375 cm/s，最大加速度为 1400 cm/s²，步行刹停减速度为 1800 cm/s²；跑步速度比旧版降低 25%，减少身体移动与步频不匹配。伤害和胜负规则沿用旧版。

## 尚未完成

侧移和倒退目前仍复用前进模板动作，虽然腿部不再静止，方向表现还需要专用持枪侧步、倒退动画与方向混合空间。尚未加入足底贴地 IK、转身动画、瞄准行走专用动作；不能视为 CS 或和平精英级成品。人物完整头部 / 服装原始贴图和官方工业大包的状态仍与 v0.4.0 相同。

Android 16 手机尚未连接实测，覆盖安装、启动、触屏移动、两设备动画同步、帧率和 16 KB 页兼容仍待设备验收。PC 与手机测试时应同时使用本次版本，并结束旧对局后重新建房。
